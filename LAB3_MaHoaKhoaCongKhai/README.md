## Hướng dẫn cài đặt và chạy chương trình
### 1. Cấu hình Cơ sở dữ liệu (SQL Server)
1. Đảm bảo SQL Server Express có cổng TCP/IP **`14333`**.
2. Mở SQL Server Management Studio (SSMS), mở và chạy (nhấn `F5`) file "01_Tao_CSDL.sql" 
  
### 2. Chạy chương trình Java (Apache NetBeans)
1. Mở Apache NetBeans (bản 20 trở lên, sử dụng JDK 17/21).
2. Chọn **File → Open Project...** và trỏ tới thư mục `LAB3_MaHoaCongKhai_TranMyQuyen`.
3. Nhấp chuột phải vào dự án chọn **Clean and Build (`Shift+F11`)**
4. Nhấn **`F6` (Run Project)** để khởi chạy giao diện chính `week_03.frm_Menu`.
